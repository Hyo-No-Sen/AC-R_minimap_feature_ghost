## すぐに試す方法

サンプルとして `master_maps` フォルダにモンテカルロのチュリニ峠の走行軌跡を格納しているので、すぐに動作を確認したい場合は、[起動方法](#起動方法)を実行してから、Time Attack でチュリニ峠のいずれかのステージで走ってみてください。これらは不要になったら削除しても構いません。

## 起動方法

1. zip ファイルを展開して、適当なフォルダに格納する(例: `c:\apps\ACR_MINIMAP`)
2. `ACR_MF_GHOST.exe` をダブルクリックなどで起動する
3. Assetto Corsa Rally を起動する

## ステージマップの作り方

1. [起動方法](#起動方法)を実行する
2. ミニマップウィンドウ(半透明の黒い四角)を右クリックして「軌跡を記録する」にチェックを入れる
   - ※初期状態でチェックされています
3. Time Attack などでマップを作りたいステージを選択し、レースを開始する
4. コースアウトしないように慎重に走行し、ゴールする
5. ミニマップウィンドウを右クリックして「レース終了」をクリックする(**重要**)
   - ※「レース終了」をクリックしないと走行軌跡がファイルに保存されません
6. `recorded_track` フォルダに JSONL 形式のファイルが保存されているので、`master_maps` フォルダにコピーする
7. 次回以降、同じステージを開始するとミニマップにコース(走行軌跡)が表示されます

## ゴーストカーを表示する方法

1. [ステージマップの作り方](#ステージマップの作り方)を実行して走行軌跡をファイルに保存する
   - ※`recorded_track` フォルダに走行軌跡が保存されていることを確認する
2. もう一度、同じステージ/車両でステージを開始する
3. ミニマップウィンドウにゴーストカーが表示されます
4. ステージ終了時に「レース終了」をクリックすると、今回の走行軌跡がファイルに保存されます
5. 次回以降、同じステージ/車両でステージを開始すると、ステージタイムが早いほうの走行軌跡をゴーストとして表示します
   - ※つまり、常に自分のコースレコード相手に練習ができます。
   - ※ステージレコードを更新したときは必ず「レース終了」をクリックしてください(レース終了を検出する方法が見つかっておらず、この操作が必要です)
   - ※レース終了を検出する方法を知っていたら教えてください

## ゴーストカーを表示しない方法

ミニマップウィンドウを右クリックして「ゴーストカーを使用する」のチェックを外してください。

## その他の操作

- ミニマップウィンドウ右クリック →「終了」すると現在の設定を保存してから終了します
- ミニマップウィンドウ上でマウス左ボタン + ドラッグ操作すると移動できます
- ミニマップウィンドウの端でマウス左ボタン + ドラッグ操作するとウィンドウサイズを変更できます
- 自車アイコンをマウス左ボタン + ドラッグ操作で自車アイコンを移動できます
- ミニマップウィンドウ上でマウスホイールを回転させると拡大縮小します
- ステージ走行中に Assetto Corsa Rally をポーズすると、マウスミドルボタン + ドラッグ操作でマップを自由にスクロールできます。ポーズを解除するかミニマップウィンドウ右上の「自車位置」をクリックすると自車位置に戻ります

## 特別な走行軌跡

`special_ghost` フォルダに格納された走行軌跡は、最優先で表示されます。つまり、とっておきの走行軌跡を格納する場所です。

## 備考

- 要するに走行軌跡を「ステージマップ」と「ゴースト」として表示しています。格納するフォルダによって役割が変わるだけです。

## 注意

- Assetto Corsa Rally はボーダレスウィンドウかウィンドウモードにしてください。フルスクリーンはダメです。
- ミニマップウィンドウの右クリックメニューが出ないときは一度ミニマップウィンドウを左クリックしてください
- Assetto Corsa Rally が操作できなくなったときは、ゲーム画面を左クリックしてください
  → アクティブウィンドウがどれになっているかを意識しながら使ってください
- PyInstaller で実行可能ファイルに変換しています。そのためアンチウイルスソフトに誤検出される可能性があります

## 免責
